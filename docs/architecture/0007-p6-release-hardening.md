# ADR 0007：P6 反向接入与发布候选加固

状态：已采纳并实现；Linux 本地候选验收证据以兼容性记录及发布指南为准，用户已决定MIT并授权GitHub0.1.0发行准备；公开推送与Release完成状态按实际证据记录。

## 背景与范围

P0–P5 已形成进程插件、管理与正向 OneBot 接入。P6 按 SKILL 的阶段合同交付反向 Universal WebSocket、升级/迁移流程、平台打包、负载与故障验证以及文档定版。Cargo 的 0.1.0 是已有工程版本；生成候选归档不等于公开发布或获得未测试平台的认证。用户已授权公开GitHub main与0.1.0发行准备；候选生成仍不自动执行推送、tag或上传，crate发布不在本次流程。

## 反向 Universal WebSocket

反向监听仍在独立 adapter-snowluma 插件中，宿主不引入 OneBot 网络实现。配置新增 `transport`，值为 `forward_ws`（默认，保留旧配置）或 `reverse_ws`。反向配置使用 `reverse_bind`（默认 `127.0.0.1:17281`）与 `reverse_path`（默认 `/onebot/v11`）；正向继续使用 `url`。反向原生仅提供 loopback WS，拒绝非 loopback 绑定，不将可选 token 当作明文远程管理的充分保护。

反向握手校验精确路径、`X-Self-ID` 与配置账号相等、`X-Client-Role: Universal`；配置 access_token 时要求精确的 `Authorization: Bearer …`。缺失、重复或冲突身份不接纳。每个适配器最多一条活动连接，重复连接被拒绝。监听端口在启动时取得，冲突使启动失败；排他替换、停止或退出释放监听。成功连接使用新连接 generation；既有事件规范化、动作 echo 关联、队列上限、超时与断连结果未知语义复用，不自动重放可能已执行的动作。

本阶段不实现 split event/API、反向 HTTP、内建 TLS 或公网监听。合成 OneBot 客户端测试不扩展已记录的真实 SnowLuma 版本验证范围。

## 发布候选与完整性

以固定工具链、Cargo.lock、前端 lock 与已验证静态资源构建。工具使用显式平台目标、可执行文件和元数据白名单，分离候选程序包与可写运行数据，携带配置 Schema、插件清单、API 文档、版本与构建信息。生成排序、归一时间/权限的归档及 SHA-256 摘要，验证完整文件集合、路径和链接边界。摘要用于检测损坏，不冒充签名或发布者身份认证。归档重现性指同一输入的打包结果；不把未验证的跨环境编译称作位级可复现。

平台矩阵显式覆盖 Linux x64、Linux arm64、Windows x64。CI 定义、交叉检查和实际运行证据分别记录。用户已决定项目MIT许可，发行须携带许可文件并核对第三方分发义务；未完成的真实平台运行仍是支持范围限制，不能通过更新版本或文档冒充运行通过。

## 备份、迁移与依赖

备份/恢复要求停止宿主与插件，环境秘密由运维单独保管。保留原始配置、修订、秘密引用、包与插件数据的一致性；恢复到新目录，先验证再切换，失败保留原目录。冷备份工具的停机检查与受支持平台必须可核查，不能把不存在 socket 当作所有平台都已停机的证明。

旧配置继续依赖默认值兼容；任意 Schema 版本之间不存在可凭空推导的通用数据转换。支持的迁移须声明源/目标与变换、离线验证和回滚步骤。不自动递增 desired/applied，不把秘密引用解析为字面量写入备份或输出。依赖更新通过锁文件审查、配置/协议回归与制品重建；不为“升级”盲目切换未验证的大版本。

## 契约与资源验证

插件作者获得可执行契约检查入口，针对显式信任的包验证结构、握手、生命周期与确定退出；显式授予权限，不自动扩大能力。可选业务接口不成为所有插件的强制协议。

持续负载验证在无 QQ 的合成进程环境运行，参数、时长、批大小与最大事件数有界，报告实际接收/拒绝/动作结果、换代与停止清理证据。4096 请求标识及 mock 历史等代次预算属于资源合同，应显式报告并按计划换代；不能将这种实验称作单代无限运行。内部指标未暴露时不虚构 pending、任务数或 RSS 上限证据。既有坏帧、超时、慢消费者、崩溃与重载回退回归继续执行。

## 验收与后果

实现需同步 Schema、插件与运行指南、CI、兼容矩阵与 CHANGELOG。实际测试通过后才能将状态改为已实现。资源测试结果受给定环境和负载约束，默认只信任本机插件的安全模型不变。
