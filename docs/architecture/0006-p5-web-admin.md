# ADR 0006：P5 Web 管理插件与授权桥接

- 状态：已实现，Linux 本地验收通过；平台运行边界见兼容记录
- 日期：2026-10-29
- 前置：[ADR 0004](0004-p3-management-config-reload.md)、[ADR 0005](0005-p4-onebot-snowluma.md)

## 决策与边界

HTTP 管理服务器与静态 WebUI 由独立 `web-admin` 插件提供。宿主不依赖 Axum、前端资源或具体插件；未启用 Web 管理时继续独立运行。P5 使用 Vue 3、TypeScript、Vite，固定依赖和锁文件。发布静态资源随插件源码保存，单独 Cargo 构建不依赖 Node；前端构建和 CI 检查资源与源码一致。

插件通过 SDK 的 `management.call` 请求访问宿主管理控制面，不直接读写宿主配置、安装根或本机管理端点。core 按当前插件身份、instance、generation 校验来源，精确检查 `management.read` / `management.write` 权限和方法白名单，以有界桥接队列送到宿主管理 actor。发送和回复均检查活跃代次；未接入桥接的嵌入式 Supervisor 返回结构化错误。

桥接可读取插件、安装包、操作、配置状态与 Schema，发起安装、启用、禁用、卸载、启停、重载和配置事务。桥接完全禁止 `plugins.call`；连接查询使用独立的 `adapter.status` 安全投影，不开放任意业务动作。只返回未解析的秘密引用；已解析令牌不能回到浏览器。配置 Schema 中 `writeOnly: true` 标记的字段，经管理桥接读取与更新时必须使用 `{$secret: "ENV_NAME"}` 引用；已有明文配置由 CLI 迁移，不生成可回写的脱敏占位符。此检查不改变本机 CLI 的既有恢复能力。配置版本使用既有 CAS，冲突不覆盖用户草稿。

## 异步操作与恢复

浏览器发起变更后收到操作 ID，再查询操作状态。宿主管理 actor 保持单写串行，长操作期间继续处理只读查询；插件桥接不使用本地 CLI 的同步等待行为，以免 Web 插件启动、停止或替换时相互等待。Web 管理自身停机或重载可能中断 HTTP 响应，不能把断开连接解释为操作没有执行。可通过 CLI 查询操作和实际状态，恢复启动或修复配置。

`web-admin` 使用 exclusive 替换，先释放旧监听器再启动新实例；绑定端口失败按既有生命周期恢复规则处理。不承诺零停机。监听任务、会话、请求和连接在退出时清理。宿主已有 CLI 与同用户本机管理端点继续作为独立恢复入口。

管理只读磁盘查询在最多 16 个阻塞任务中执行，准入不等待配额，任务实际结束才释放配额；共享视图只在复制快照时持锁。包安装/校验等耗时磁盘变更同样离开单线程异步调度器。`plugins.installed` 仅检查有界安装元数据并返回 `verified:false`，不是当前文件内容完整性证明；安装、启用、重载仍执行完整校验。前端运行状态每 2.5 秒刷新，库存定时刷新间隔为 30 秒。

## HTTP 与认证

P5 默认绑定 `127.0.0.1:17280`，仅接受 loopback IP。管理令牌通过配置的秘密引用注入，至少32字节，不预置默认密码。登录后使用有上限与过期时间的不可预测会话，Cookie 为 HttpOnly、SameSite=Strict；令牌不存储在浏览器持久存储中。

HTTP 校验实际绑定地址对应的 Host，拒绝不可信 Origin。登录使用 JSON 请求；所有管理 RPC 和退出会话同时检查 Cookie、精确 Origin 与 `X-CSRF-Token`。只读 RPC 也采用同一检查，前端不通过跨域方式访问管理 API。无 Origin 的同源页面导航允许读取静态资源，带不可信 Origin 的请求被拒绝。不支持通过随意 Host/端口反向代理绕过地址校验。

限制登录速率、请求体、并发、超时、会话数量和桥接队列。错误响应不透传可能含路径或插件私有数据的任意诊断。前端文本显示不使用任意 HTML 注入，静态 CSP 不允许远端脚本或内联脚本。管理诊断日志只显示有限操作记录的安全投影，不展示原始 stderr、聊天正文或秘密。
